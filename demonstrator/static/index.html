    4 · What this does not show

    • All labeled data comes from one curing run (five sausages). Held-out scores separate sausages, not runs, so they are probably optimistic for a new run.
    • Each prediction uses a short window of the latest uplinks. It reflects the current sensor levels, not the full history of the run.
    • The labels are human phase annotations, not a measured ground truth for food safety or quality. Model outputs are estimates, not decisions.
    • "Confidence" is the model's own probability, not a calibrated guarantee. The three models have different calibration, so compare their labels, not their confidence values.
